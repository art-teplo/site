# Бэкенд

Общие правила — в `../AGENTS.md`. Перед правками прочитай `README.md`: локальный запуск, структура, правила Python/DRF, каталог и импорт, права менеджеров, Telegram и хранилища. Архитектура и деплой — `../docs/stack.md`, раздел 7.

- Зависимости — uv (`pyproject.toml` и `uv.lock`); форматирование и линт — `ruff.toml`.
- Новые настройки из env отражай в `../root/.env.example` и `../root/docker-compose.yaml`, как описано в README. Значения секретов не выводи.
- Изменение модели сопровождай миграцией. Изменение API, полей каталога или тегов кэша проверяй вместе с фронтом; поведение полей админки описывай в `../docs/admin-guide.md`.
- Перед импортом или изменением файлов выясни, к какой базе и хранилищу подключена команда. Локальная среда может использовать тот же S3, что и сервер: удаление или замена файла затронет общий бакет.
- Для разработки используй тестового Telegram-бота; один токен нельзя одновременно опрашивать локально и на сервере.
- После правок кода: `uv run ruff check && uv run ruff format --check && uv run pytest`. Нужен Postgres из dev-compose (README). При изменении моделей дополнительно: `uv run python src/manage.py makemigrations --check --dry-run`, как в CI.
