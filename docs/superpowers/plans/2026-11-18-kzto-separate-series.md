# КЗТО: план разделения серий и загрузки материалов

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Делегирование реализации — только если отдельно выбрано пользователем. Коммитов без просьбы пользователя нет.

**Статус:** локальная реализация и приёмка завершены 2026-11-18, без коммитов, push и релиза. Итоговые данные — [результат локальной проверки](../../research/2026-11-18-kzto-local-result.json), проверки — `.superpowers/sdd/2026-11-18-kzto-separate-series/progress.md` в корне проекта. Последнее уточнение фото/цветов — решение № 188; исторические пункты ниже не являются новым заданием на повторный перенос.

**Goal:** Отдельные H/V, В/Г, P/S серии КЗТО с точными вариантами и собственными материалами заводских страниц.

**Architecture:** Категория XML соответствует конкретной серии. Явная команда переноса перемещает существующие варианты с сохранением PK и цен; последующий импорт обновляет именно эти серии. Галерея и файлы синхронизируются по подтверждённым источникам, с учётом происхождения и без удаления файлов S3.

**Tech Stack:** Django/DRF, Postgres, существующий импорт XML/HTML, хранилище проекта, Next.js 16.

**Spec:** [Согласуемый дизайн](../specs/2026-11-18-kzto-separate-series-design.md).

## Global Constraints

- Разрешена локальная реализация, пилот и затем перенос с загрузкой материалов.
- Только КЗТО; состав и девять пар адресов заданы в спецификации. Конвекторы и исключения сохраняются.
- Сохранять PK вариантов, цены, наценки, группы цветов и ручные данные; неоднозначность — ошибка предварительной проверки.
- Общий S3: не удалять/заменять существующие объекты; секреты не выводить.
- Начать с NEO 50 H/V, затем остальные пары и материалы всех 28 серий радиаторов.
- Не выполнять Git-коммиты, push или серверный деплой без отдельной просьбы.

## Review Focus

- Повторный импорт после разделения не пропускает перенесённые варианты и не восстанавливает объединение.
- Группы цветов с новыми ID не ломают доступность цветов и цены вариантов.
- Один общий PDF у нескольких серий не дублируется в хранилище и не удаляется вместе с одной связью.
- Ошибка сети или HTML вместо PDF/XLSX не уничтожает уже работающую галерею.
- Старый `?v=` H не открывает V и не сбрасывает выбранный артикул.
