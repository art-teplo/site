# Галерея: план превью под счётчиком «+N»

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Коммитов без просьбы пользователя нет.

**Статус:** выполнено локально 2026-11-18; дальнейшее уточнение № 188: только у КЗТО «+N» на шестом месте, остальные бренды сохраняют исходное поведение.

**Goal:** Показывать счётчик оставшихся фотографий поверх миниатюры первого скрытого фото.

**Architecture:** Существующая кнопка `Lightbox` сохраняет действие и счётчик. Внутри добавляется маленький `Picture` первого скрытого изображения, поверх — затемнение и текст; большие скрытые изображения не монтируются.

**Tech Stack:** Next.js 16, React, CSS Modules, существующие `Picture` и `Lightbox`.

**Spec:** [Раздел «Отдельная небольшая задача»](../specs/2026-11-18-kzto-separate-series-design.md).

## Global Constraints

- Шесть обычных превью, включая видео, если оно есть; счётчик только оставшихся фото.
- Для Retta 6SP — шесть фото и превью седьмого с «+9».
- Седьмое изображение загружается только как маленькая миниатюра до открытия, а не как большой кадр.
- Сохранить клавиатуру, `aria-label`, открытие первого скрытого кадра, листание и Esc.

## Review Focus

- При видео вторым кадром первый скрытый номер фото отличается от седьмого.
- Смена цвета/положения меняет порядок и фон кнопки без устаревшего индекса.
- При шести и менее кадрах кнопка отсутствует.
- Контраст счётчика сохраняется на светлом и тёмном фото.
- Узкая горизонтальная лента не растягивает страницу.
