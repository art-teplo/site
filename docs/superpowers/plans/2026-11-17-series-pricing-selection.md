# Наценка серии и выбор радиатора — план реализации

> Исполнение в текущей сессии по шагам, без коммитов и деплоя. Согласованный вариант — закреплённая панель.

**Goal:** независимая наценка серии, переходы по реальным размерам и возврат к цене выбранного варианта.

**Architecture:** наценка хранится у Series, price_byn остаётся рассчитанным полем Variant. Списки размеров входят в кэшируемые детали серии и выбираются в браузере. Панель использует существующий выбор варианта и функцию прокрутки.

**Tech Stack:** Django 6, PostgreSQL, Next.js 16, React, CSS Modules, существующие токены.

**Spec:** `docs/superpowers/specs/2026-11-17-series-pricing-selection-design.md`.

## Global Constraints

- Без новых зависимостей, изменений сервера, коммитов и сброса текущих цен.
- Сохранить предыдущие незакоммиченные правки документации.
- CSS использует токены, API остаётся совместимым для старого фронта.

## Review Focus

- Две серии одного бренда с разными наценками не влияют друг на друга.
- При миграции сохраняется каждый старый процент; откат не теряет различающиеся проценты молча.
- Шаги не ограничены первой страницей таблицы и не включают неактивные варианты.
- Произвольный ввод и движение от/до работают на краях и при пустом поле.
- Панель не показывает устаревшую цену, не перекрывает контент и исчезает после ухода со страницы.

## Результат проверки 2026-11-17

- Бэкенд: 380 тестов прошли; Ruff и проверка формата — без ошибок. Дополненный тест миграции отдельно подтвердил обратный перенос одинаковых процентов и отказ от потери разных процентов при откате. `makemigrations --check --dry-run`: изменений нет.
- Фронт: lint и production build прошли; 5 тестов шагов диапазона и форматирования размеров — зелёные.
- Браузер: 375/768/1440 px, выбор и снятие выбора, панель/цена, переход к цене, ручная граница 170, шаги 121 → 181 → 241; переход Quadrum 40 → Quadrum 60 и Back с сохранённой скрытой страницей. Горизонтального выхода нет.
- Ревью: исправлены общий якорь цены для сохранённых страниц Next и потеря длины конвектора в сводке. Используется уникальный якорь по slug и единый форматтер с первым экраном.
- Производительность локально: для Quadrum 40 (348 вариантов) получение шагов с чтением категории заняло 8,47 мс, для Pilon (17 836 вариантов) — 18,72 мс; сами массивы занимают 746/855 байт. Тест отдельного агрегата подтверждает один SQL-запрос. Это локальный замер, не нагрузочный тест сервера.
- Миграция применена только к локальному dev-каталогу: 65 428 вариантов, количество и сумма цен до/после совпали. Локальный worker перезапущен для нового расчёта. Продакшен, коммиты и удалённые ветки не менялись.
