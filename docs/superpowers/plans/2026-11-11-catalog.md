# Каталог: серии, варианты, цвета — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Заменить демо-товары фронта настоящим каталогом: серии и варианты в базе, импорт xlsx Guardo и Nova, перевод цен по курсу Нацбанка, список с формфакторами и страница серии с таблицей вариантов, цветами и чертежом.

**Architecture:** Бэк (`apps.catalog`) хранит серии, варианты (исполнение — поля, особенное — `attrs`), группы цветов с процентом и курсы; фильтры и счётчики считает бэк по схеме категории из кода. Фронт рендерит первый экран на сервере через `data/api.ts` (кэш по тегу `catalog`), а смену фильтров и выбор варианта — в браузере запросом в `/api/catalog/…`; в демо (`NEXT_PUBLIC_DEMO=1`) — та же логика по демо-данным.

**Tech Stack:** Django 6, DRF, Unfold, Postgres, Celery beat (`django_celery_beat`), openpyxl (новая зависимость); Next.js 16 (Cache Components), TypeScript, CSS Modules.

**Spec:** `docs/superpowers/specs/2026-11-11-catalog-design.md`. Решения 123–128 в `docs/decisions.md`.

## Review Focus

1. Курса ещё нет (первый запуск, API Нацбанка лёг) — варианты в RUB/EUR/USD показывают «Цена по запросу», сортировка по цене ставит их в конец, ничего не падает. Тест — Task 3.
2. Цвет недоступен у выбранного варианта (технолак Pilon есть не у всех) — в таблице такой вариант при фильтре по цвету не показывается, в заявку сочетание не попадает. Тест — Task 5.
3. Параметр адреса испорчен или устарел (`?v=` несуществующего артикула, `height_min=abc`, `color=` неизвестного кода) — страница открывается без выбора варианта / фильтр игнорируется, а не 500 или 400. Тест — Task 5 (бэк), Task 10 (фронт: `parseCatalogQuery`).
4. Повторный импорт того же файла не создаёт дублей и не трогает описание, фото и проценты групп; пропавший из файла вариант становится неактивным и пропадает с сайта. Тест — Task 6.
5. У серии нет формфакторов (Showcase) или фото — список всё равно показывает одну карточку серии с минимальной ценой и заглушкой фото. Тест — Task 4.

### Task 4: Схема категорий, фильтры и API списка

- Produces:

  - `filters.parse(params: QueryDict, fields: list[Field]) -> dict[str, tuple | list]` — `<key>_min` / `<key>_max` (числа; не число — пропустить), `<key>=a,b`; `brand`, `color` (код `Color`), `execution` (`'<tubes>-<connection>'`, `0` — без трубности).
