# Импорт Радимакс

1. Собрать исходную таблицу из трёх прайсов. Хранить цены BYN за секцию, допустимые количества, парные размеры монтажа и происхождение строки. Проверить контрольные суммы Loft 350, Соул и Стилл.
2. Добавить повторяемый локальный импорт с предварительным просмотром. Использовать прямые варианты каталога, группу стандартных цветов Стилл и текст об окраске по запросу. Сохранять видимость и ручные настройки при повторе.
3. Отобрать чистые материалы из локальной папки, Яндекс Диска и заводских страниц. Сохранить реестр для повторной загрузки и проверить пилотные серии в изолированной локальной БД и хранилище.
4. Загрузить остальной подтверждённый ассортимент, сверить числа вариантов, цены и материалы. Выполнить проверки бэкенда.
