# Анализ визуальных референсов

Источники: `DESIGN.md` (палитра и токены, приоритет по визуалу), supahero.io/hero/did-global-cinema (DGC), три скриншота из `design-photos/`, логотип из `old-version/wp-content/uploads/2025/01/`. Дополнительные сайты производителей (Tubes, Antrax) снять headless-браузером не удалось — сайты не отдали страницу; в анализ не вошли.

## 1. Что говорит каждый референс

### DESIGN.md — «тёплое редакционное ателье»
- Кремовая бумага `#e4dfd9` как основной холст, белые карточки, графит `#171717` для тёмных поверхностей и главных кнопок.
- Один хроматический акцент, и тот как знак препинания (точка после заголовка, индикатор). Никаких заливок акцентом.
- Две роли шрифта: редакционный display weight 500 с трекингом −0.02em и тихий UI-гротеск.
- Радиусы 8 / 12 / 20 / pill, одна мягкая тень `0 6px 27px rgba(0,0,0,.07)`, волосяные линии `#c7c7c7`.
- Ритм: полноэкранные фото-полосы чередуются с тихими текстовыми блоками; текст выровнен влево, ширина строки 500–600px.
- Фото — главный визуальный элемент: кинематографичный кроп, глубокие чёрные, янтарный свет.

### DGC (supahero)
- Почти чёрный кадр, по боковым краям — **красное свечение**, как от рампы или раскалённого металла. Зерно плёнки по всей площади.
- **Уголки видоискателя** по углам кадра — рамка без рамки.
- Заголовок — широкий (extended) гротеск капсом, по центру, поверх ленты кадров.
- Навигация — мелкий капс с большим трекингом; у CTA «Get in touch» красная точка. Внизу служебные подписи (язык, таймкод).
- Красный строго дозирован: свечение и точка; основной текст — светлый на чёрном.

### Pinterest 1 — мебельный лендинг «Sofa»
- Тёмный интерьер в тёплом свете на первом экране, крупный светлый заголовок по центру, одна светлая кнопка.
- Дальше чёрный блок «Why Sofa»: заголовок слева, предмет справа, ниже три пункта с номерами «1/ 2/ 3/».
- «Best Selling Product»: заголовок слева, фильтр-табы справа (активный — светлая плашка), лента карточек-фото в край экрана.
- Берём: нумерацию «01/», вкладки-пилюли, ленту карточек, заходящую за край.

### Pinterest 2 — палитра Arounda
- Тёмно-коричневый холст `#161316` → `#453027` с **оранжево-красным свечением из угла**, как от огня в камине.
- Стеклянные пилюли с тонкой светлой обводкой.
- Берём: свечение от угла как «тепло» и полупрозрачные пилюли на тёмном. Не берём: оранжевую заливку и стекло на светлых секциях.

### Pinterest 3 — карточка товара «675 Chair»
- Белый лист на фоне: галерея слева (миниатюры вертикально + большое фото на светло-сером), справа название, цена, **варианты кружками-свотчами** с подписями капсом, количество и одна тёмная кнопка.
- Ниже две колонки «Description»: заголовок слева, текст справа.
- «Dimensions»: чертёж с размерами + таблица с волосяными линиями, значения справа серым.
- «You might also like»: заголовок слева и стрелки, справа карточки на светлом фоне.
- Берём почти целиком: асимметричные двухколоночные секции (заголовок слева, контент справа), таблицу характеристик на волосяных линиях, свотчи цветов, чертёж-схему габаритов радиатора.

### Логотип
- Узкий (condensed) гротеск: «ART» красный `#E6332A`, «TEPLO» белый, под ним «СТУДИЯ ТЕПЛА» разреженным капсом.
- Белая часть рассчитана на тёмный фон → в коде логотип инлайн-SVG: красный фиксирован, остальное `currentColor`.

## 2. Синтез: один организм

**Идея: «тепло в темноте».** Кремовые редакционные страницы (DESIGN.md) — это дневной свет комнаты. Тёмные полосы (DGC + Arounda) — это вечер у камина: графит, зерно, красное свечение с краёв. Сайт чередует их, и переход между ними — главный сквозной приём.

| Элемент | Решение |
| --- | --- |
| Холст | кремовый `#e4dfd9`; тёмные полосы — графит `#171717` и глубокий «уголь» `#0e0c0b` |
| Акцент | красный логотипа `#E6332A` занимает роль «ember dot» из DESIGN.md: точки, индикаторы, подчёркивание активного, свечение. Без заливок кнопок и фона |
| Свечение | радиальный градиент красного (и `#ff6a1f` в самой горячей точке) с краёв или из угла тёмных секций, мягкий, без резких границ |
| Зерно | SVG-шум поверх тёмных секций, ~6% непрозрачности, статичный |
| Рамка | уголки видоискателя на первом экране и вокруг крупных фото — сквозной мотив «смотрим на дом через кадр» |
| Display | ~~Unbounded~~ → **Onest** 500 (см. decisions.md, п. 4). Было: **Unbounded** 400–500: широкий гротеск с полной кириллицей — ближайшая к «Söhne Breit» из DESIGN.md и к extended-капсу DGC; тянется к узкому логотипу контрастом ширины |
| Текст | ~~Golos Text~~ → **Onest** 400. Было: **Golos Text** 400/500/600: нейтральный, кириллица — родная (ParaType), не Inter |
| Сетка | 12 колонок, контейнер 1200px (DESIGN.md), фото-полосы — на всю ширину; секции асимметричные: заголовок в колонках 1–4, контент 6–12 |
| Метки | мелкий капс с трекингом +0.08em и номер «01/» — единый формат подписи над каждой секцией |
| Карточки | белые на креме, радиус 20, одна тень; на тёмном — без белых карточек, только фото с затемнением |

## 3. Типографика

Шкала из DESIGN.md (14 / 16 / 19 / 23 / 28 / 69), шаг ~1.2 в текстовой части; display — скачок к 69px. На мобильных крупные размеры адаптивные через `clamp()`.

| Роль | Шрифт | Размер | Межстрочный | Вес |
| --- | --- | --- | --- | --- |
| display (только hero) | Unbounded | clamp(36, 6vw, 69) | 1.1 | 500 |
| heading | Unbounded | clamp(23, 3vw, 28)… крупные секционные — clamp(28, 4vw, 44) | 1.2 | 400 |
| heading-sm | Unbounded | 23 → 19 | 1.3 | 400 |
| subheading | Golos | 19 | 1.4 | 400 |
| body | Golos | 16 | 1.5 | 400 |
| caption / label | Golos | 14 / 12 капс | 1.2 | 500 |

Отступление от DESIGN.md: заголовки секций крупнее 28px (до 44). Причина — у Unbounded широкий глаз, и при широких асимметричных секциях 28px теряется. 69px остаётся только у hero.

## 5. Движение — один язык

- **Плавный скролл:** Lenis, отключается при `prefers-reduced-motion`.
- **Reveal:** fade + сдвиг 24px вверх, `--dur-slow`, `--ease-out`, stagger 80ms у соседей. Один компонент `Reveal` на весь сайт.
- **Параллакс:** только фото внутри рамки (лёгкий сдвиг на 8%), через CSS scroll-driven animations с прогрессивным улучшением. Нигде больше.
- **Свечение** тёмных секций медленно «дышит» (opacity 0.85↔1, 6s) — единственная фоновая анимация; отключается при reduced motion.
- **Интерактив:** hover — сдвиг стрелки на 4px и смена фона, `--dur-fast`; active — `scale(.98)`; focus-visible — кольцо 2px красного с отступом 3px.
- Анимируются только `transform` и `opacity`.

## 6. Что берём и что нет

**Берём:** кремовый холст и монохром DESIGN.md; красное свечение, зерно, уголки кадра и красную точку у CTA (DGC); тёплый свет из угла (Arounda); нумерованные пункты, табы-пилюли, ленту карточек за край («Sofa»); карточку товара целиком — галерею, свотчи, чертёж и таблицу на линиях («675 Chair»).

**Не берём:** ленты кадров в hero с автопрокруткой (тяжело и отвлекает); стекло на светлом; оранжевую заливку; агрессивный капс-заголовок на всю ширину — у нас display в обычном регистре, капс только в метках; центрирование всего подряд (центр только у hero); рейтинги-звёзды, «Last 3 left», корзину из карточки «675 Chair».
