# Доработки каталога — результат 19.11.2026

Выполнено локально по [утверждённому перечню](2026-11-19-catalog-follow-up.md). Коммит, пуш и релиз не выполнялись.

- Общая схема определяет фильтры и колонки; новые зарегистрированные поля attrs проходят общий вывод. Диапазоны и текстовый множественный выбор единообразны. Постоянные значения вынесены в характеристики; частично неизвестное поле не объявляется постоянным. Активные пустые значения можно снять.
- Конвекторы и полотенцесушители не получают фиктивное «Стандартное, без термоклапана» из пустого подключения.
- Монтаж сохранён в данных/таблицах и ограничениях КЗТО, убран из самостоятельных фильтров. Новая direct-группировка охватывает все монтажи; старые точные ключи поддерживаются. Configured-конфигурации остаются точными и различаются подписями при необходимости.
- Фасеты снимают только собственный фильтр. Общий агрегат уменьшает повторный расчёт предложений. Первый запрос каталога использует параметры адреса, без первоначальной общей выдачи.
- В серии админка объясняет источник цены и ведёт к действующим прайсовым вариантам либо правилам доплат.
- Существующие группы Any RAL видны в каталоге/палитре карточки; `any-ral` фильтрует доступные предложения с ценой по запросу, конкретные группы `any-<id>` сохраняются. Новые возможности окрашивания не добавлялись.
- Nova: одна витрина с прежним стилевым фото, без размера и предвыбора. Сама серия, варианты, цены и галерея не переделывались.
- Удалено 7 доказанно лишних родителей КЗТО, включая Quadrum 40. 83 записи материалов перенесены скрытыми с сохранением PK/ключей файлов. 18 архивных записей сохранены как технические опоры старых цветов, проектов или видео. Физические файлы общего S3 не менялись.
