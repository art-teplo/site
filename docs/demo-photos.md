# Демо-фото и логотипы

**Временно, для оценки вида сайта.** 2026-10-29 все 57 слотов из [images-manifest.md](images-manifest.md) заполнены снимками с сайта заказчика kztoradiator.by и фото моделей с официального guardo.ru. Плейсхолдеры сохранены вне репозитория.

Что важно:

- Фото подобраны по смыслу, но **не соответствуют товарам один к одному**: у Nova, Royal Thermo, Carisa, SR, Радимакс в карточках стоят интерьеры КЗТО и Guardo. Перед запуском заменить по манифесту.

- Фото с kztoradiator.by принадлежат заказчику (или КЗТО) — подтвердить, что их можно использовать на art-teplo.by.
